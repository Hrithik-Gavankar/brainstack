# Examples

This directory contains realistic BRAIN.md profiles for different engineering roles.

## Available profiles

| Directory | Role | Stack |
|-----------|------|-------|
| `backend-engineer/` | Senior Backend Engineer | Go, PostgreSQL, Kubernetes, gRPC |
| `frontend-engineer/` | Frontend Engineer | React, TypeScript, Tailwind, Storybook |
| `devops-engineer/` | DevOps Engineer | Terraform, Kubernetes, AWS, GitHub Actions |
| `platform-engineer/` | Platform Engineer | Python, Go, Backstage, Crossplane |
| `oss-maintainer/` | OSS Maintainer + Day Job | Go, Rust, Community Management |

## How to use

1. Browse the example closest to your role
2. Copy it to your workspace as a starting point
3. Replace the example data with your own
4. Run `engineer-brain update` to auto-populate from your git history

These examples demonstrate the depth and structure of a well-configured BRAIN.md.
