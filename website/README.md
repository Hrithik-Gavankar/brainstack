# Documentation Website

This directory contains the Brainstack documentation site built with [Docusaurus](https://docusaurus.io/).

## Development

```bash
cd website
npm install
npm start
```

This starts a local development server at `http://localhost:3000`.

## Build

```bash
npm run build
```

Generates static content in the `build/` directory.

## Deployment

The site can be deployed to GitHub Pages, Vercel, Netlify, or any static hosting provider.
