# BRAIN.md Specification

`BRAIN.md` is to engineers what `README.md` is to projects.

It's a structured Markdown file that documents you — your skills, your work patterns, your active projects, your growth trajectory. Designed to be consumed by AI coding assistants.

## Why a new file standard?

| File | Documents | Consumed By |
|------|-----------|-------------|
| `README.md` | Projects | Humans, GitHub |
| `package.json` | Node.js apps | npm, bundlers |
| `pyproject.toml` | Python projects | pip, build tools |
| **`BRAIN.md`** | **Engineers** | **AI assistants** |

## Sections

Every BRAIN.md contains:

1. **Identity** — Name, role, experience, career goal
2. **Career History** — Longitudinal context across roles
3. **Skills Inventory** — Proficiency-tagged skill table
4. **Active Repositories** — What you're working on now
5. **Expertise Map** — Strong / Growing / Dormant classification
6. **Work Patterns** — Commit types, velocity, schedule, style
7. **Sprint Context** — Active branches and recent achievements
8. **Growth Areas** — Roadmap, strengths, learning log

## Proficiency Levels

| Level | Criteria |
|-------|----------|
| **Strong** | 10+ commits or 3+ PRs in the area |
| **Growing** | 2-9 commits or 1-2 PRs |
| **Exposure** | Repo cloned, files read, minimal hands-on |
