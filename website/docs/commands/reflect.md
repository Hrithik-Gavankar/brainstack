# reflect

Analyze current patterns and provide actionable feedback.

## Usage

```
engineer-brain reflect
```

## What it does

1. Scans the last 30 days
2. Reads BRAIN.md
3. Applies pattern detection
4. Generates a reflection report

## Output format

```
## Reflection — 2026-07-13

### What You're Doing Well
[Specific patterns and evidence]

### Habit Observations
- Work hours, commit frequency, PR size, fix-to-feature ratio

### Blind Spots
[Cooling repos, skipped work types, stale goals]

### Recommendations
1. [Actionable suggestion]
2. [Actionable suggestion]
3. [Actionable suggestion]
```

## Recommended frequency

Weekly — Friday afternoons work well as a week-in-review.
