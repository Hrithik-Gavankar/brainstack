# Roadmap

See the full [roadmap on GitHub](https://github.com/Hrithik-Gavankar/engineer-brain/blob/main/docs/roadmap.md).

## Highlights

### Now (v1.0)
- Core engine with 6 platform adapters
- Commands: sync, update, quarterly, reflect
- Pattern detection and auto-expertise classification
- `engineer-brain doctor` command (coming soon)

### Next (v1.x)
- Zed, JetBrains, Neovim support
- Web dashboard for pattern visualization
- MCP server integration
- Team-level brain (opt-in aggregation)

### Later (v2.0)
- BRAIN.md as an open standard
- Native tool integration
- Organization-level intelligence
